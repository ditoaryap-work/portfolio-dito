## Context and goal

CoffeeSpace is a responsive landing page for a coffee brand. It needed to introduce the brand and give the visit a more interactive path.

## What we built

The website was built with Next.js and Hono. Its interface animation uses GSAP and Framer Motion.

## My role and decisions

I built the page and composed animation for the user's journey. Two motion libraries offer different animation options, but each adds code and needs a clear purpose.

## Results and impact

The responsive landing page and interactive flow were developed. The project notes do not include usage, performance, or conversion figures after release.

## Trade-offs and questions to measure

Using two animation libraries expands motion choices while adding JavaScript and maintenance work. I would measure page performance and review whether each effect needs both libraries in another iteration.

## What I learned

Choosing motion tools for specific needs keeps the code easier to maintain. The next measure of success is not the number of animations; it is a responsive page that feels alive without slowing down its information.
